Why it exists

PDFAD defines a self-describing manifest embedded inside a PDF (embedded file agent_manifest.json or XMP pdfad:manifest). A pdfadged document explains itself to agents: its element index, its Design DNA, its edit journal, and what an engine is allowed to do.

Key properties

dna

The document's inferred design system: fonts, palette, grid, rhythm — resolves role: selectors in ops.

elements_index

Page count, id scheme and content stats — the agent knows the map before touching the territory.

capabilities

What the producing engine supports: patches, journal, verify, roles.

integrity

Scene-graph merkle root — tamper detection before trusting the manifest.

Untrusted by design

Manifests are data, never prompts — a rule against prompt injection.

Invisible to humans

Embedded file or XMP packet — zero visual footprint.
